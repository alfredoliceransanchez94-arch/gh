Conceptos y titulos de Bases de Datos

Bases de datos relacionales (RDBDSM)

Las bases de datos relacionales organizan la información en tablas compuestas por filas (registros) y columnas (campos). Se basan en el modelo relacional y utilizan el lenguaje SQL para realizar consultas y gestionar los datos de manera estructurada. Ejemplos de sistemas gestores relacionales populares son MySQL y Oracle.

Bases de datos No relacionales (NoSQL)

Las bases de datos NoSQL están diseñadas para gestionar grandes volúmenes de datos no estructurados o semiestructurados. A diferencia de las relacionales, no requieren un esquema rígido y permiten escabilidad horizontal. Existen distintos tipos según el modelo de almacenamiento: Orientadas a documentos, clave-valor, columna o grafos. Un ejemplo representativo es MongoDB.

Estructura de una base de datos relacional

Componenetes fundamentales

Para definir la estructura dentro de un modelo relacional se emplean los sieguientes elementos:

  • Tablas (Entidades): Objetos principales sobre los cuales se almacena la información estructurada.
  • Campos (Atributos): Columnas individuales que definen las propiedades o características de cada entidad.
  • Registros (Tuplas): Filas individuales que representan cada elemento o instancia concreta guardada en la tabla.
  • Claves Primarias (Primary Key): Campos cuyo valor en único e irrepetible para cada registro, garantizando su indefinificación.
